# Yudh for Windows

Mac 版 Yudh（`../nippo`）的 Windows 伴随程序。电脑主要用来打游戏，所以只做这几件事、尽量不占资源：

1. **英语**：单词卡 / 考点词 / 听写，和 Mac 共用同一份进度（同步文件夹里的 `english-events-*.jsonl`）。听写和 Mac 一样用系统语音读（英式优先，没装就用美式并在卡上写明）。
2. **明天的会**：只读 Mac 写的 `agenda.json`，不碰日历。
3. **泡完澡后的日课**：和 Mac 同一套（跟练视频用官方播放器 → 肩颈拉伸 → 躺着做腹式呼吸）。视频写了时长的（链接后面写 `4:04` 或 `4 分 35 秒`）放完自动跳下一个；没写的会自己记住：YouTube 用播放器报的时长，bilibili 用第一次看到点「跟练完了，下一个」为止的时间（下一屏可以撤销），写回设置里那一行，下次就自动跳。拉伸和力量按时间自动往下走，没有语音播报；以及站起来时的 3 次腹式呼吸。连续天数和隔天力量按两台设备加起来算（同步文件夹里各自写一个 `habits-<设备名>.json`，读的时候相加）。
4. **坐站**：**播报，不是问答**。计划固定（坐 30 分钟 → 站 30 分钟循环，不用调），到点小窗直接说「站起来」（撕胶带 + 喷漆的声音），接着 3 次腹式呼吸（喷漆在纸上随吸气漫开、呼气收回）、每次必做的斜角肌拉伸（左右各两个角度 × 20 秒）、再轮 1 个肩颈动作（这一步剩几秒用模板大字，离屏幕一臂也看得见；每一步到时间自动往下走，换步是模板板落在混凝土上的一声），做完两下喷点、15 秒后自己关；30 分钟后说「坐下」（罐子放下的一声），写着这次站了几分钟和「今天站了 N 小时 N 分，换了 N 次姿势」，15 秒后自己关。它默认你照做了；说错了就把**「坐 | 站」的牌子**翻过来——这个牌子在小窗、窄条、托盘首行和「今天」页上都是同一个：刚被叫的 90 秒内翻等于「我还坐着 / 我还站着」（10 分钟 / 5 分钟后再叫），之后翻等于现在就换。离开座位 3 分钟以上，切换等你回来再说，走开的那段不算站立；坐着离开则重新计时（「我还坐着」的 10 分钟约定要 10 分钟没操作才作废）；电脑睡眠后醒来从头算。**夜里 23 点到早上 8 点不叫，日课做完当天也不叫**（设置里可改时间；在 Mac 上做的日课也算，5 分钟内生效）。立起来后小窗走步骤的这几分钟就算不碰键鼠也不当作离开。全屏游戏时不弹，但**连续玩 60 分钟以上，关掉游戏就马上让你站起来**（读图、切出去不到 5 分钟不算关掉）。注意事项「拉伸感可以，发麻就停」每天只在第一次出现。

格式以 `../nippo/docs/sync-format.md` 为准。

## 结构

```
core/      yudh-core：没有界面的 Rust 库（这里的逻辑全部有测试，在 Linux 上也能跑）
  event    同步事件一行（键按字母序、空字段不写、时间 UTC 毫秒）
  replay   去重 → 排除撤销 → 按 (at, id) 重放 → 卡片 + 答题记录
  srs      SM-2（和 Swift 的 SRSState.applying 同一组用例）
  queue    出题顺序（复习优先 → 当天新词额度）
  english  给界面用的入口：出题、评分、知道了、加词、恢复、撤销、统计
  sync     同步文件夹：只写自己的文件（临时文件 + 替换，内容没变不写）
  library  词表（同步文件夹的 english-library/）
  agenda   明天的会：没有文件 / Mac 还没更新 / 没有会 / 会议列表
  posture  坐站的播报时钟：到点自己切换、「坐 | 站」翻转（90 秒内是纠正）、夜间休息、游戏宽限、切换记录和一天的胶带印记
  standing 每天站了多久、换了几次、胶带的印记（把时钟的记录按天相加，写在设置文件里）
  ritual   日课：视频链接解析与嵌入地址、视频时长、拉伸每一步的秒数、腹式呼吸节拍与记录
  habits   日课 / 呼吸记录的跨设备合计（只写自己的 habits-<设备名>.json，读时把别的设备加上）
```

没有本地数据库：自己的 `english-events-<设备名>.jsonl` 就是自己的正本，状态每次从所有设备的事件重放出来（几千行，毫秒级）。

## app（Tauri 2 外壳）

```
app/
  src-tauri/   Rust：托盘、30 秒一次的坐站判定（全屏游戏判定、离开座位判定）、给界面的命令
  ui/          面板 index.html（英语 / 明天 / 设置）、坐站小窗 posture.html、日课 ritual.html
               素材 material/ 和字体 fonts/ 在构建前从 ../../nippo/Resources 复制（不进 git）
  scripts/copy-assets.mjs
```

- 常驻的只有托盘。面板、坐站小窗、日课窗口都是要用时才创建，关掉就销毁；面板关掉时连词表一起释放内存。
- 面板：点托盘图标先出一条窄的（「坐 | 站」牌子 · 已坐 / 已站几分钟 · 今天站了多久、换了几次 · 打开），用的是烤好的黑带 `strip-black-night`；点「打开」才往上长成整块（今天 / 英语 / 明天 / 设置），底边不动，黑带淡出、面板框向上展开。「今天」是首页：姿势牌子和下一次切换的时间、一天的胶带时间轴（黑 = 坐，青 = 站，灰 = 离开 / 游戏 / 休息，橙色刻痕 = 现在，虚线 = 这段的计划）、呼吸、英语、日课、明天第一个会各一行。设置里的「拉伸库」把五段文本变成了对象：每个拉伸一行（姿势图 · 名字 · 时长 · 步数），点开改步骤，「试做」在小窗里走一遍；存储仍是文本。设置里还能把窄条设成常驻（失焦不关，10 秒没碰变淡；展开的面板失焦或按 Esc 回到窄条；托盘图标和「打开面板」在常驻时是展开 / 收起，不会关掉窄条；开机和关掉游戏后自动出现时不抢焦点）。不常驻时再点托盘图标就关（点下去的瞬间面板已经因为失焦关掉了，松开时不会再打开）。出现在鼠标所在屏幕的可用区域右下角（任务栏在哪条边都不会挡住），失去焦点就关（选文件夹时除外）。Esc 关闭。窄条和「今天」每 30 秒更新一次，只读时钟本身（不读英语、会议、习慣的文件）。托盘菜单只建一次，之后只改文字（菜单开着时也不会消失）。夜里和日课之后「坐 | 站」牌子是灰的、不能翻。面板和坐站小窗都能拖，位置会记住（面板记左下角）。会议链接、「在浏览器里打开」走系统默认浏览器。第一次打开先讲计划（坐 30 站 30，到点会叫你），同步文件夹放在设置里以后再选。
- 坐站小窗从胶带处向下展开出场、揭走关闭、换步时内容落下、数字换时「盖章」一下（只动 transform / opacity，最长 220 ms，prefers-reduced-motion 时只做透明度）。声音是 `ui/sounds/*.wav`（用 numpy 合成的撕胶带 + 喷漆 / 模板板落地 / 两下喷点 / 罐子放下，读不到时退回正弦波），WebView2 用 `--autoplay-policy=no-user-gesture-required` 启动，不用点过页面也能响。
- 字：欧文和数字 Archivo，中文标题用 Noto Sans CJK SC Black 的子集（`fonts/NotoSansCJKsc-Black-subset.woff2`，只含界面用到的字，OFL），正文仍是雅黑；中文行里的数字包一层 `.num` 把基线对齐。模板数字一个角色一个尺寸：小窗倒计时 count-black（字高 40），呼吸 timer-black，日课舞台 mid-black。
- 默认开机自启（只进托盘）；设置里可以关。重复双击启动时不会再开一个，只会把面板打开。
- 打游戏时完全安静（反作弊对策，默认 AION2：`Aion2.exe` / `Aion2-Win64-Shipping.exe`，设置里可改）：名单里的程序在运行时，
  Yudh 关掉自己所有窗口、不再创建任何窗口，也不再读键鼠空闲和全屏状态，只留托盘图标（提示变成「游戏中，已暂停」）；游戏关掉后自动恢复。
  判断只看进程列表里的程序名（Toolhelp 快照，和任务管理器一样），不打开、不读取游戏进程。
  Yudh 本来就不读写游戏内存、不注入、不装驱动、不挂键鼠钩子、不模拟按键、不截屏。但反作弊的规则不公开，没人能保证；最稳妥的是开游戏前从托盘退出 Yudh。
- 视觉沿用 Mac 夜版烤好的素材：九宫格用 CSS `border-image`（`bleed` 用外扩，`insets` 对应切片），模板字用字形图集。
- 在浏览器里预览界面：`cd app/ui && python3 -m http.server`，打开 `index.html`（`?welcome=0` 看首次说明）/
  `posture.html?prompt=standing&phase=announce|breath|stretch|done`、`posture.html?prompt=sit`、`posture.html?preview=1` / `ritual.html`
  （不在 Tauri 里时，`js/mock.js` 提供示例数据）。

## 安装包

GitHub Actions（`.github/workflows/yudh-windows.yml`）在 windows-latest 上 `npm run build`，
产物在运行页面的 Artifacts「Yudh-Windows-setup」（NSIS 安装包，装在当前用户下，不需要管理员权限）。

本地（Windows）：

```
cd app
npm install
npm run dev      # 开发
npm run build    # 安装包：target/release/bundle/nsis/
```

## 第一次使用

1. 安装包没有代码签名，Windows 会弹 SmartScreen「已保护你的电脑」：点「更多信息」→「仍要运行」。只有第一次。
2. 第一次打开面板会先讲坐站计划，点「知道了」。英语和会议才需要：设置 → 同步文件夹，选和 Mac 设置里同一个文件夹（OneDrive 等）。
3. 这台电脑的名字：默认是计算机名，不要和 Mac 同名。
4. Mac 设置里要打开「把今天和明天的会议写给 Windows」和「把词表复制一份给 Windows」，Windows 才有明天的会和单词。
5. 听写用 Windows 自带的英式英语语音读；没装英式时用美式，设置的「高级」里会写明和怎么装。日课没有语音播报。
