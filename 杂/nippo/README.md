# Yudh（原 Nippo）

居家办公用的 macOS 菜单栏 app（个人用）：盯着今天的会议、提醒别一直坐着，碎片时间背英语。
界面是中文，短的标签和喊声用英文（TUESDAY、NEXT、NOW、NEW、NICE!、CLEAR!、STAND UP）。日期只显示英文星期，任何地方都不显示几月几日。
外观是「Phantom Glass」（v10）：ペルソナ5 出「形」，iOS 27 出「材质」，青橙两色不变。
形：所有带字的面都是「剪纸的札」——黑纸白字、白纸黑字、青/橙纸黑字，边是斜的，右上角咬一口。日程和任务是菜单：每行一块黑纸，选中的那行变成关卡色并出现 ▶，悬停变白纸。
英文喊声一律斜体宽体大写（TUESDAY、NEXT、SCHEDULE、TASKS、NICE!），小札歪 3〜4°；中文永远直立。主角的大数字压在墨迹上（墨迹是和色面相反的颜色），NICE!/MISS 是锯齿的爆裂形。
材质：面板窗口本身是 Liquid Glass（透出桌面），顶部的切换和底部的状态条是玻璃胶囊，选中的青色透镜滑动变形；次要按钮是玻璃，主要按钮是青/橙实心剪纸。玻璃上只放图标、数字和 13pt 以上的粗体，正文永远在不透明的纸上。
不重叠：答题的章有自己的槽（指令列上方），数字有自己的格，任何札都不压在按钮或文字上。
图形叙事：底部状态条只有图标和数字（椅子 47、学士帽 3天后、电源），「已工作」是公文包 + 3:12，「线上」是摄像机图标。
坐站小窗是一块玻璃：上块是关卡色剪纸（人形图示 + 一句问句），下块是黑色剪纸（拉伸的姿势图示 + 「秒 / 次」的数字札 + 一行动作 + 步骤点）。
拉伸图示按名字和步骤里的关键词自动选（肩胛 / 下巴 / 颈 / 胸 / 转肩 / 呼吸 / 走），自己在设置里改了拉伸也有图。
面板浮在屏幕中央（不再挂在菜单栏图标下面）：点菜单栏图标打开，拖动「TUESDAY」那块札可以移动，位置会记住；点外面、按 Esc 或再点图标关闭。小窗拖上块可以移动。
晚上（19:00–07:00）青和橙会稍微压暗一点，免得刺眼。
字号只有 12（标签）、13（补充）、15（正文）、22（标题），加上大数字、单词和章；宽体 / 窄体 / 斜体只给英文和数字。
页面里不放 app 图标。图标是紫底 + 荧光绿墨迹（2026-09-30 去掉了中间的「Y」；源文件 `Resources/AppIcon/AppIcon.svg`）。
界面按 OOUI（面向对象的 UI）组织：从会议、任务、单词这些「对象」的列表里选一个，再对它做操作。
不向任何外部服务发送数据（只用日历、通知和 macOS 自带的朗读）。

## 构建与启动

```bash
IELTS_DIR=~/Downloads/ielts-dist-v71 ./build-app.sh   # 第一次：导入英语素材并构建
./build-app.sh                                        # 之后（已导入的素材会继续用）
open dist/Yudh.app
```

生成 `dist/Yudh.app`（需要 Command Line Tools，不需要 Xcode；导入素材需要 node）。旧的 Nippo 会被退出并删除。
需要 macOS 26 及以上。第一次启动时请允许通知和日历权限。登录时总会自动启动（没有开关）。

英语素材（`Resources/English/`）含有从教材里抽取的词表，所以没有放进公开仓库（已加入 `.gitignore`）。
也可以用 `node scripts/import-english.mjs <IELTS app 文件夹>` 单独导入。

### 素材与版权

- 词典 `dict.json`：ECDICT（MIT，Copyright (c) 2017 skywind3000）的精简版。导入脚本会把许可全文写进 `Resources/English/LICENSES.txt`，随 app 一起打包
- 考点词 `paraphrase.json`、语料 `dictation.json`、单词 `vocab.json`：摘自刘洪波《雅思考点词真经》、王陆《雅思王听力真题语料库》和 IELTS app 的分级词池，
  只供个人学习。`Resources/English/` 和 `dist/`（里面的 .app 同样含这些词表）都在 `.gitignore` 里，不要把 .app 发给别人

## 面板布局

从上到下按「现在重要的顺序」排成一列：

- 顶部：英文星期（TUESDAY）、已工作时间（小字）、标签页（今日 / 英语，⌘1 / ⌘2；选中的瓦片是当前关卡色）
- 今日：主角是一张铬黄的关卡卡——选中的会议（默认是下一个会议）的标题和「加入会议」在色布上，倒计时的大数字在黑里布上；
  5 分钟内或进行中整块变朱红，已结束变灰。卡片下面是褶皱时间线（工作时段每格 15 分钟，灰格是会议，关卡色是选中的会议），
  再下面是今日日程和当前任务
- 英语：单词 / 考点词 / 语料 / 词典，右边的图标在卡片和列表之间切换。卡片是翠绿的关卡卡：题在色布上，
  答题按钮在黑里布上竖着排；做完了变成玫瑰粉的 CLEAR!。卡片下面是 20 格的今日进度。会议开始前 30 分钟起，顶部会出现一行会议条
- 底部一行：坐姿、下一次シャチョケン、电源图标（按两下退出，⌘Q 直接退出）。设置用 ⌘, 打开（没有按钮）

## 用法

- 工作时间：在顶部输入上班时间，比如「853」（= 8:53），顶部会小小地显示「已工作 3 小时 12 分」。点它可以修改。第二天自动清空。不和考勤系统联动
- 当前任务：在备忘里写任务名（顶格）和内容（Tab 缩进或「- 」开头），会按层级显示，空行分隔任务。
  每个任务显示为「任务名 + 一行灰色的内容」，左边的方框点一下就是完成（从备忘里移除，刚完成时可以撤销）。「编辑」时边写边保存，关掉面板也不会丢
- 下一次シャチョケン（26卒_新卒社長研修）：在日历未来 90 天里找标题含「新卒社長研修」或「シャチョケン」的日程
  （可在设置里改，不区分全角半角），在底部显示「3 天后」。鼠标悬停可以看到标题和日期
- 会议：点今日日程里的一行就选中那个会议，上面的主角区显示标题、加入按钮和倒计时（默认是下一个会议）。
  菜单栏显示「定例MTG 还有5分钟」。开始前 5 分钟（可设置）发带加入链接的通知
- 站立与拉伸（升降桌）：坐满 45 分钟，屏幕上方弹出朱红的小窗「站起来了吗？」（把桌子升到手肘 90°、顺便喝杯水）。
  按「站起来了」后小窗变翠绿，显示站立剩余时间（默认 15 分钟）和一格一分钟的褶皱条，并一步一步显示拉伸动作（上一步 / 下一步）。
  到点后钴蓝的小窗问「坐下了吗？」。推迟之后再弹出时还是同一个拉伸动作。小窗出现在鼠标所在的屏幕。
  「15 分钟后」「再站 5 分钟」可以推迟。小窗不会抢焦点。底部只显示状态（「已坐 23 分钟」，到点了加上「该站起来了」），点击打开小窗。
  Google Meet 会议中和开始前 5 分钟不弹，结束后再问（没有 Meet 链接的日程不算会议）。坐着时 3 分钟以上没有操作，就当作离开座位，重新计时。
  默认的拉伸动作都很温和、手臂不举过头顶，胸廓出口综合征也常被推荐。可以在设置里换成医生或理疗师给的方案（空行分隔，第 1 行是名字，后面每行一个步骤）
- 休息日：周末、日本节假日（按《国民の祝日に関する法律》自动计算）和在设置里登记的休假日，会暂停会议提醒和站立提醒。
  站立提醒只在工作日的工作时间内（默认 9:00–18:00，可设置）。日历里的全天日程既不显示，也不用来判断
- 英语（碎片时间）：用 IELTS app 的素材，一题十秒左右，只用键盘就能刷。每天目标 20 题，并记录连续天数。
  复习按间隔重复（SM-2，和 IELTS app 同一套公式），记录保存在数据库里。每答一题会提示「storey → 3 天后再复习」，⌘Z 可以撤销上一题
  - 单词：分级词池 4,313 个，按 B1 → B2 → C1 → C2 → A2 的顺序，每天 10 个新词。空格看释义，1〜4 打分
    「忘了 / 模糊 / 记住了 / 太简单」。「已经会了」以后不再出（可在列表的「已掌握」里恢复）
  - 考点词：刘洪波《考点词真经》的同义替换 555 个（听力 179 → 阅读）。四选一：真题里它会被换成哪个词（干扰项每次从别的词里重新抽）。
    1〜4 作答，回车下一题
  - 语料：王陆语料库 6,441 个（名词 → 形容词副词 → 连读吞音 → 综合 → 场景），听英式朗读写单词。
    差 1 个字母算「差一点」，按「模糊」计分（新词明天再出）。为了不在办公室突然出声，第一题要自己按「播放」（⌘R）
  - 词典：ECDICT（MIT）的精简版 3.3 万词，会去掉词形变化再查。查到的词可以加进单词卡
  - 答对盖「NICE!」、答错盖「MISS」的章。今天的份做完了会显示「CLEAR!」
  - 列表：按「今天 / 学习中 / 已掌握」筛选出现过的词，点一行用卡片打开，还没到期也可以复习
- 设置：打开面板时按 ⌘,。设置窗口打开期间，Dock 里会暂时显示图标

保存位置（默认 `~/Documents/日報/`，可在设置里修改）：`nippo.sqlite`、`nippo.log`。

## 开发

```bash
swift run nippo-tests   # 测试（CLT 没有 XCTest，所以用自带的简易测试运行器）
swift build             # 检查能否编译
```

重画图标后，用 `node scripts/make-icon.mjs` 重新生成 `Resources/AppIcon/AppIcon.icns`
（需要 `npm i -g playwright && npx playwright install chromium`）。旧的计划文档在 `docs/archive/`。
用 `swift run NippoApp` 运行时，英语素材从仓库的 `Resources/English/` 读取。

节假日由 `Sources/NippoCore/Schedule/JapaneseHolidays.swift` 按日本《祝日法》计算（不用每年更新）。
因修法临时增加的节假日，请在设置的「休息日」里添加。
