# Yudh(旧 Nippo)

今日の会議と、座りっぱなしを見張り、すきま時間に英語をやる在宅勤務向けの macOS メニューバーアプリ(個人用)。
見た目はゲームの UI(スプラトゥーン 3 の HUD とメニュー画面のつもり):黒いステージに黄緑とすみれのインク、斜めに切った札とコマンド、
ゲージ、選択カーソル「▶」、正解で「NICE!」のスタンプ。システムのライト/ダークに関係なく常に黒いステージ。
文字は黒・濃い灰・黄緑・白・すみれの面の上だけに置き、斜めにするのは英字の見出しと札の形だけ(日本語の本文はまっすぐ)。
画面の中にアプリアイコンは出さない。アイコンはすみれの地に黄緑のインクと斜体の「Y」(元絵 `Resources/AppIcon/AppIcon.svg`)。
画面は OOUI(オブジェクト指向 UI)で組んである:会議・タスク・単語という「もの」の一覧から 1 つを選び、そのものに付いた操作をする。
外部サービスには何も送らない(カレンダー・通知・macOS 内蔵の読み上げだけを使う)。

> 2026-09-28 に日報・週報・月発表・メモ・今日のやること・会議の字幕/録音/議事録・
> 初めて聞いた言葉・1on1 助手・検索・日本語アシスタント・ブログ支援・スクリーンショット整理を廃止した。
> 2026-09-29 に打刻(バクラク勤怠)まわりも廃止した。
> 2026-09-29 に Nippo から Yudh へ改名した。設定・権限・データを引き継ぐため、バンドル ID(`jp.michiteki.nippo`)・
> 保存先・Swift のモジュール名は Nippo のまま。同日、英語タブ(IELTS アプリの素材)を足し、設定ボタンを外した。
> 過去の生成物(`reports/`・`週報/`・`minutes/` など)と DB 内の既存データは削除せず残してある。

## ビルドと起動

```bash
IELTS_DIR=~/Downloads/ielts-dist-v71 ./build-app.sh   # 初回:英語タブの素材を取り込んでビルド
./build-app.sh                                        # 2 回目以降(取り込んだ素材はそのまま使う)
open dist/Yudh.app
```

`dist/Yudh.app` を作る(要: CLT・Xcode 不要。素材の取り込みには node)。旧 Nippo は終了・削除される。
要: macOS 26 以降。初回起動時に通知とカレンダーの権限を許可すること。
ログイン時には常に起動する(切り替えは無い)。

英語タブの素材(`Resources/English/`)は IELTS アプリの教材由来の語表を含むので、公開リポジトリには入れていない
(`.gitignore` 済み)。`node scripts/import-english.mjs <IELTS アプリのフォルダ>` でも取り込める。

## メニューの並び

よく見るものほど上に。横長で、開いてすぐ全体が見える(中段が画面より高いときだけスクロール)。

- 上の帯:日付(黄緑のインク)・タブ(今日 / 英語、⌘1 / ⌘2)・WORK(勤務時間のゲージ。1 コマ 1 時間)
- 今日タブ:左に MISSION(選んだ会議。既定は次の会議。件名・参加・残り時間)と QUEST LOG(今日の予定)、右に QUESTS(タスク)
- 英語タブ:単語・考点词・語料・辞書。それぞれカード(1 つ)と一覧(まとまり)。今日の数は TURF ゲージ、連続日数は COMBO。
  会議の 30 分前からは上に会議の帯
- 下の帯:SIT / STAND(座り・立ちの時間のゲージ。満ちたら切り替えどき)・EVENT(次のシャチョケン)・電源アイコン
  (2 回押しで終了。⌘Q はすぐ終了)。設定は ⌘, で開く(ボタンは無い)

## 使い方

- 勤務時間: 上の帯の入力欄に出勤時刻を「853」(= 8:53)のように入れると、今日の勤務時間
  (「勤務 3:12 8:53〜」)を小さく表示。押すと修正(英語タブでは入力欄を出さない)。翌日は未入力に戻る。勤怠システムとは連携しない
- いまのタスク: メモに、タスク名(字下げなし)と中身(Tab 字下げか「- 」)を書くと階層で表示。
  空行でタスクを区切る。各タスクの左の四角で完了(メモから消す。直後なら「元に戻す」)。
  「編集」中は書くそばから保存するので、パネルを閉じても消えない
- 次のシャチョケン(26卒_新卒社長研修): カレンダーの 90 日先までから、件名に「新卒社長研修」または
  「シャチョケン」(設定で変更可・全角半角を区別しない)を含む次の予定を、下の帯に「10/2(金) 16:00 · 3日後」のように表示。
  ホバーで件名
- 会議: 今日の予定の行を押すとその会議を選び、上のブロックに件名・参加ボタン・残り時間を出す(既定は次の会議)。
  メニューバーに「定例MTGまで 5分」のカウントダウン。
  開始 5 分前(設定可)に参加リンク付き通知
- 立ち作業・ストレッチ(昇降デスク): 座って 45 分で画面上部に小窓「立ちましたか?」
  (「デスクを肘 90° の高さに」「立つついでに水を一杯」)。「立った!」を押すと立ち作業の残り時間
  (既定 15 分)のカウントダウンと、ストレッチの手順を 1 つずつ(次へ/戻る)表示。時間になると
  「座りましたか?」。「15分後」「あと5分」で先送り。小窓はフォーカスを奪わない。
  メニューの下の帯には状態(「座り 23分 · 11:45 ごろ立つ」)だけを出し、押すと小窓を開く。
  Google Meet の会議中と開始 5 分前は出さず終了後に尋ねる(Meet のリンクが無い予定は会議扱いしない)。
  座っているあいだ 3 分以上操作がなければ離席とみなして計り直す。
  既定のストレッチは胸郭出口症候群でも勧められる、腕を頭より上げない穏やかな動き。
  設定で担当医・理学療法士のメニューに置き換え可(空行区切り、1 行目が名前・続く行が手順)
- お休みの日: 週末・日本の祝日(祝日法から自動計算)・設定で登録した休暇日は、会議通知と
  立ち作業リマインドを止める。立ち作業リマインドは勤務日の勤務時間(既定 9:00–18:00、設定可)だけ。
  カレンダーの終日予定は一覧にも出さず、判定にも使わない
- 英語(すきま時間):IELTS アプリの素材で、1 問 10 秒前後・キーボードだけで回せる。
  1 日 20 問が目標(連続日数つき)。復習は間隔反復(SM-2、IELTS アプリと同じ式)で、記録は DB に残る。
  答えるたびに「storey → 3日後にまた」のように次を知らせ、⌘Z で直前の答えを取り消せる
  - 単語:分層詞池 4,313 語を B1 → B2 → C1 → C2 → A2 の順に 1 日 10 語。Space で意味、1〜4 で
    「もう一回 / あいまい / 覚えた / 簡単」。「知ってる」でもう出さない(一覧の「知ってる」から戻せる)
  - 考点词:刘洪波 考点词真经の同義替換 555 語(聴力 179 → 阅读)。真題での言い換えを 4 択(誤答は毎回ほかの語から作る)。
    1〜4 で答えて Enter で次へ
  - 語料:王陆 语料库 6,441 語(名詞 → 形容詞副詞 → 連読吞音 → 総合 → 場面)を英国英語の読み上げで書き取る。
    1 文字ちがいは「おしい」で明日もう一度。職場でいきなり音を出さないよう、最初の 1 回は自分で「聞く」(⌘R)を押す
  - 辞書:ECDICT(MIT)の抜粋 3.3 万語。語形変化を外して引く。引いた語は単語カードに足せる
  - 一覧:出たことのあるものを「今日 / 学習中 / 知ってる」で絞って見る。行を押すとカードで開き、期限前でも復習できる
- 設定: ⌘,(パネルを開いているとき)。設定ウインドウを開いているあいだだけ Dock にアイコンが出る

保存先(既定 `~/Documents/日報/`、設定で変更可): `nippo.sqlite`・`nippo.log`。

## 開発

```bash
swift run nippo-tests   # テスト(CLT に XCTest が無いため自製ランナー)
swift build             # コンパイル確認
```

アイコンを描き直したら `node scripts/make-icon.mjs`(要: playwright)で `Resources/AppIcon/AppIcon.icns` を作り直す。
`swift run NippoApp` で動かすときは、英語タブの素材をリポジトリの `Resources/English/` から読む。

祝日は `Sources/NippoCore/Schedule/JapaneseHolidays.swift` が祝日法から計算する(年ごとの更新不要)。
法改正による臨時の祝日は、設定の「休暇日」に追加する。
