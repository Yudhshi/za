# Yudh（原 Nippo）

居家办公用的 macOS 菜单栏 app（个人用）：盯着今天的会议、提醒别一直坐着，碎片时间背英语。
界面是中文，短的标签和喊声用英文（TUESDAY、NEXT、NOW、NEW、NICE!、CLEAR!、STAND UP）。日期只显示英文星期，任何地方都不显示几月几日。
外观是 v12「Stencil Turf」（夜间版）：模板喷漆 × 地盘格。面板是一块浇筑的混凝土（左上光、两个灌了砂浆的对拉孔、边角小崩口），
上面的东西只有两种做法——**喷**（透过模板纸喷出来：主角卡、主按钮、章、模板大数字，飞沫只落在纸外一侧）和**遮**（贴胶带遮出来的硬边：标签、评分块、格子、复选框）。
材质全部是预先烘焙的 @2x PNG（`Resources/Material/`，由 `scripts/material/` 生成），SwiftUI 只负责摆放、九宫格拉伸和淡入；文字、中文、图标都是真的。
颜色：荧光青 + 荧光橙 + 漆黑 + 白漆 + 会议灰。平时（「静」）主角卡是黑漆块 + 青色模板数字，荧光色不超过画面的 15%；
会议 10 分钟内 / 进行中 / 到点 / 坐站提醒 / 答题章（「动」）整块喷成青色，黑色模板字，下沿挂 ≤ 3 条垂滴；倒计时到 00 变橙。橙色永远不直接碰青色（中间隔一圈黑漆）。
字体：拉丁字母和数字用 Archivo（可变字体，宽体 / 粗细直接走轴），时间、计数、键位用 JetBrains Mono，中文日文用系统的 PingFang 并且永远直立、不拉宽、不加模板桥。两套字体随 app 打包（`Resources/Fonts/`，SIL OFL）。
一周七只神兽（只画兽、不画神）：平时的主角卡上，当天的神兽是喷在黑漆块上、文字下面的第二层灰漆模板（看明天时是明天的），按轮廓避开文字和大数字、能多大就多大；英语 20/20 通关时作为青色奖章出现，坐站小窗的牛皮纸上有一层很淡的残影。界面上不写它们的名字和来历。
动效只有几个时刻，每一帧都是烘焙的：会前 10 分钟青漆从大数字往外漫开、垂滴长出来；开会那一刻橙漆从模板桥渗出来漫满；答题时章的模板纸落下、喷、揭开；本轮地盘的一格从雾点喷满；通关时奖章喷上；每天第一次打开面板时揭掉遮盖纸。平时什么都不动，「减少动态效果」时直接显示最后一帧。
坐站小窗是贴在混凝土上的牛皮纸：顶端一条皱纹纸胶带当把手（STAND UP / STRETCH / SIT DOWN），主按钮是青色喷漆块；站立中的拉伸用一条古埃及壁画式的三格带（做完的淡、当前的满、之后的只剩模板空框），「转肩」的箭头换成了哪吒的混天绫。
面板浮在屏幕中央（不再挂在菜单栏图标下面）：点菜单栏图标打开，拖动「TUESDAY」可以移动，位置会记住；点外面、按 Esc 或再点图标关闭。小窗拖顶上的胶带可以移动。
现在只有夜间版；日间版（浅色混凝土）以后按同一套 tokens 另做一组素材。
页面里不放 app 图标。图标是紫底 + 荧光绿墨迹（2026-09-30 去掉了中间的「Y」；源文件 `Resources/AppIcon/AppIcon.svg`）。
界面按 OOUI（面向对象的 UI）组织：从会议、任务、单词这些「对象」的列表里选一个，再对它做操作。
不向任何外部服务发送数据（只用日历、通知和 macOS 自带的朗读）。

## 构建与启动

```bash
IELTS_DIR=~/Downloads/ielts-dist-v71 ./build-app.sh   # 第一次：导入英语素材并构建
./build-app.sh                                        # 之后（已导入的素材会继续用）
open dist/Yudh.app
```

生成 `dist/Yudh.app`（需要 Command Line Tools，不需要 Xcode；导入素材需要 node）。旧的 Nippo 会被退出并删除。
需要 macOS 26 及以上。第一次启动时请允许通知和日历权限。登录时总会自动启动（没有开关）。

英语素材（`Resources/English/`）含有从教材里抽取的词表，所以没有放进公开仓库（已加入 `.gitignore`）。
也可以用 `node scripts/import-english.mjs <IELTS app 文件夹>` 单独导入。

## 面板布局

从上到下按「现在重要的顺序」排成一列：

- 顶部：英文星期的模板字（TUESDAY）、已工作时间、标签页（今日 / 英语，⌘1 / ⌘2；选中的是一小块白漆）
- 今日：主角卡是选中的会议（默认是下一个会议）——喊声 NEXT / NOW、时间、标题、倒计时的模板大数字、时长格。
  平时是黑漆块 + 当天的神兽；会前 10 分钟到会议结束整块喷成青色（黑字、垂滴、带黑圈的橙色「加入会议」）；开始的头 1 分钟是橙色的 00。
  今天的会都开完了，主角卡改成明天第一个会（TOMORROW + 星期 + 明天的神兽）。
  下面是上班到下班的盘面（默认 9:00–18:00，每格 15 分钟；灰格是会议，青格是选中的会议，橙色刻度是现在），再下面是日程和任务
- 英语：单词 / 考点词 / 语料 / 词典。白漆的单词卡在左，右边是章（NICE! / MISS）的槽和本轮 4×5 的地盘格（漆的满度 = 评分）。
  释义没翻开时被两道黑漆盖住。做满 20 题是通关页：20/20 + 当天神兽的青色奖章。会议开始前 30 分钟起，顶部会出现一行会议条
- 底部一行：坐姿、下一次シャチョケン、电源图标（按两下退出，⌘Q 直接退出）。设置用 ⌘, 打开（没有按钮）

## 用法

- 工作时间：在顶部输入上班时间，比如「853」（= 8:53），顶部会小小地显示「已工作 3 小时 12 分」。点它可以修改。第二天自动清空。不和考勤系统联动
- 当前任务：在备忘里写任务名（顶格）和内容（Tab 缩进或「- 」开头），会按层级显示，空行分隔任务。
  每个任务显示为「任务名 + 一行灰色的内容」，左边的方框点一下就是完成（从备忘里移除，刚完成时可以撤销）。「编辑」时边写边保存，关掉面板也不会丢
- 下一次シャチョケン（26卒_新卒社長研修）：在日历未来 90 天里找标题含「新卒社長研修」或「シャチョケン」的日程
  （可在设置里改，不区分全角半角），在底部显示「3 天后」。鼠标悬停可以看到标题和日期
- 会议：点今日日程里的一行就选中那个会议，上面的主角区显示标题、加入按钮和倒计时（默认是下一个会议）。
  菜单栏显示「定例MTG 还有5分钟」。开始前 5 分钟（可设置）发带加入链接的通知（45 分钟以上的会加一句「倒杯水带进去」）
- 站立与拉伸（升降桌）：坐满 40 分钟，屏幕上方弹出朱红的小窗「站起来了吗？」（把桌子升到手肘 90°、顺便喝杯水）。
  按「站起来了」后小窗变翠绿，显示站立剩余时间（默认 15 分钟）和一格一分钟的褶皱条，并一步一步显示拉伸动作（上一步 / 下一步）。
  到点后钴蓝的小窗问「坐下了吗？」。推迟之后再弹出时还是同一个拉伸动作。小窗出现在鼠标所在的屏幕。
  「15 分钟后」「再站 5 分钟」可以推迟。小窗不会抢焦点。底部只显示状态（「已坐 23 分钟」，到点了加上「该站起来了」），点击打开小窗。
  Google Meet 会议中和开始前 5 分钟不问站坐，会议结束 1 分钟后再问（5 分钟以上的会开完 10 分钟内问时写「开完会，已坐 N 分钟」；没有 Meet 链接的日程不算会议）。
  麦克风或摄像头连续 30 秒以上在被使用时也当作在开会（日历里没有的临时会、Slack 通话、超时的会），连续 30 秒以上不用才算挂断，挂断 1 分钟后再问；
  会前 5 分钟以后才开始的、5 分钟以上的通话挂断了，日历上的会还没到结束时间也当作开完了（上一个会的通话拖到这个会的开始不算）。通话中也不自动朗读英语。只看有没有在用，不录音、不需要授权；
  菜单底部的状态会显示「通话中」，日志里记下是哪个 app 在用麦克风（某个 app 一直开着麦克风时好查原因）。
  坐了 10 分钟以上、10 分钟内有 Meet 会议时，小窗问「站着开会？」（胶带 MEETING，会议名、几点开始、多长；45 分钟以上的会提醒倒杯水带进去）：
  「站着开」从这时算站立时间，会议中不打扰，开完再问坐不坐；「坐着开」就等开完再提醒站起来（会被取消或提前结束就不等）。
  开始前 5 分钟内、上一个会刚结束时也会问，会议开始或接通后自动关掉；按了「15 分钟后」的那段时间不问。
  坐着时 3 分钟以上没有操作，就当作离开座位，重新计时（开会、通话时听着不动不算；自动弹出的「站起来了吗？」10 分钟没回应也没操作，同样算离开）。
  临时加的会：app 每 30 秒读一次 macOS 日历，日历一变就马上重读；工作时间内每 5 分钟请系统检查一次 Google 等账户要不要同步
  （系统觉得数据不旧就不会重新同步）。真正决定快慢的是「日历」App → 设置 → 账户 → 刷新日历，建议设成「每分钟」。
  默认的 7 个拉伸针对斜角肌（脖子侧面到锁骨上方）发紧：斜角肌拉伸（手按锁骨下方固定第一肋，头向对侧倒，抬头 / 正侧 / 低头三个角度）、
  W 字收肩、腹式呼吸（斜角肌是辅助吸气肌，用胸口吸气会一直绷着它）、扩胸、肩颈三步（含收下巴）、耸肩放松、走一走，每次站起来轮到一个。
  手臂都不举过头顶。可以在设置里换成医生或理疗师给的方案（空行分隔，第 1 行是名字，后面每行一个步骤）
- 腹式呼吸（用碎片时间养成习惯）：每次站起来，小窗先带你做 3 次腹式呼吸（吸 4 秒、呼 6 秒，约 30 秒；可以跳过），再进入拉伸；
  会议提醒里也会提示「开会前先做 3 次腹式呼吸」。记录今天做了几次、连续几天（和 Windows 加在一起算：同步文件夹里各写一个 `habits-<设备名>.json`）。设置里可以关掉
- 泡完澡后的日课：晚上和休息日，面板底部出现「泡完澡了」。点开后按顺序播放跟练视频（bilibili / YouTube 官方播放器，不下载），
  然后先做站着的拉伸：斜角肌、颈后（肩胛提肌）、横臂拉肩后侧（三角肌后束 · 小圆肌）、背后轻拉手腕（冈上肌 · 三角肌中束）、
  背后扣手抬臂（三角肌前束）、靠墙网球放松（小圆肌 · 冈上肌）；隔天在地上加 6 分钟肩袖力量（手对手的等长外旋、拿一瓶水侧卧外旋、俯卧 W，
  不需要弹力带）；最后在地上做猫牛式和穿针式，仰躺收下巴 + 腹式呼吸收尾。休息日的拉伸约 13 分钟，力量日多 5 分钟；
  累的晚上可以在窗口里切换成简版（约 5 分钟）。每一步先用中文语音读一遍，读完再开始倒计时，到时间自动进入下一步。
  不放睡姿拉伸（侧卧压前臂）：它会挤压肩峰下，横臂拉伸对肩后侧的效果更好。视频、拉伸、力量都能在设置里改
- 休息日：周末、日本节假日（按《国民の祝日に関する法律》自动计算）和在设置里登记的休假日，会暂停会议提醒和站立提醒。
  站立提醒只在工作日的工作时间内（默认 9:00–18:00，可设置）。日历里的全天日程既不显示，也不用来判断
- 英语（碎片时间）：用 IELTS app 的素材，一题十秒左右，只用键盘就能刷。每天目标 20 题，并记录连续天数。
  复习按间隔重复（SM-2，和 IELTS app 同一套公式），记录保存在数据库里。每答一题会提示「storey → 3 天后再复习」，⌘Z 可以撤销上一题
  - 单词：分级词池 4,313 个，按 B1 → B2 → C1 → C2 → A2 的顺序，每天 10 个新词。空格看释义，1〜4 打分
    「忘了 / 模糊 / 记住了 / 太简单」。「已经会了」以后不再出（可在列表的「已掌握」里恢复）
  - 考点词：刘洪波《考点词真经》的同义替换 555 个（听力 179 → 阅读）。四选一：真题里它会被换成哪个词（干扰项每次从别的词里重新抽）。
    1〜4 作答，回车下一题
  - 语料：王陆语料库 6,441 个（名词 → 形容词副词 → 连读吞音 → 综合 → 场景），听英式朗读写单词。
    差 1 个字母算「差一点」，按「模糊」计分（新词明天再出）。为了不在办公室突然出声，第一题要自己按「播放」（⌘R）
  - 词典：ECDICT（MIT）的精简版 3.3 万词，会去掉词形变化再查。查到的词可以加进单词卡
  - 答对盖「NICE!」、答错盖「MISS」的章。今天的份做完了会显示「CLEAR!」
  - 列表：按「今天 / 学习中 / 已掌握」筛选出现过的词，点一行用卡片打开，还没到期也可以复习
- 设置：打开面板时按 ⌘,。设置窗口打开期间，Dock 里会暂时显示图标

保存位置（默认 `~/Documents/日報/`，可在设置里修改）：`nippo.sqlite`、`nippo.log`。

## 开发

```bash
swift run nippo-tests   # 测试（CLT 没有 XCTest，所以用自带的简易测试运行器）
swift build             # 检查能否编译
```

重画图标后，用 `node scripts/make-icon.mjs` 重新生成 `Resources/AppIcon/AppIcon.icns`
（需要 `npm i -g playwright && npx playwright install chromium`）。旧的计划文档在 `docs/archive/`。
用 `swift run NippoApp` 运行时，英语素材、材质和字体都从仓库的 `Resources/` 读取。

材质（`Resources/Material/*@2x.png` + `manifest.json`）用 `python3 scripts/material/make.py` 重新烘焙（numpy / scipy / Pillow，全部约 9 分钟，详见 `scripts/material/README.md`）。
改了画面或素材后，用 `python3 scripts/material/check_ids.py` 检查 Swift 里用到的素材 id 是否都在 manifest 里。
模板图标的源文件是 `scripts/material/icons.svg`，改了之后用 `python3 scripts/material/icons_swift.py` 重新生成 `Sources/NippoApp/StencilIcons.swift`（需要 `pip install svgelements`）。
缺了某张材质时界面会退回纯色和真文字，不会崩溃。

节假日由 `Sources/NippoCore/Schedule/JapaneseHolidays.swift` 按日本《祝日法》计算（不用每年更新）。
因修法临时增加的节假日，请在设置的「休息日」里添加。
